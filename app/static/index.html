How uploads work

The file is sent in chunks: equal-sized pieces uploaded separately, several at a time. The server checks each chunk against its SHA-256 checksum, so a damaged piece is rejected instead of stored. If the transfer stops, choose the same file again to resume: only chunks the server is missing are sent.
